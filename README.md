# Essência de Criatividade — loja com pedidos por WhatsApp

## O que faz
Vitrine responsiva, filtro por categoria, busca, sacola com quantidades e mensagem de pedido pelo WhatsApp. Sem pagamento online e sem banco de dados. Usa cores e fontes do brand book fornecido.

## Como publicar
1. Crie um repositório GitHub em conta de **adulto responsável**. Envie os arquivos, inclusive pastas iniciadas por `_` e `.pages.yml`.
2. Em **Settings → Pages**, selecione **Deploy from a branch**, `main`, pasta `/ (root)`; o GitHub Pages processará o Jekyll.
3. Em https://app.pagescms.org, entre com a conta GitHub do adulto, autorize o repositório e abra **Produtos da Lojinha**.
4. Cadastre nome, foto, categoria, preço e marque **Disponível para pedidos**. O produto de exemplo vem **desativado** e não aparece na loja.
5. Em **Configurações da loja**, informe o WhatsApp Business do **responsável adulto** no formato `5544999999999` (número ilustrativo; substitua pelo real). Não coloque números particulares da criança.
6. As alterações são salvas no GitHub e publicadas após o build do Pages.
7. Teste pelo celular antes de inserir o link na bio do Instagram.

## Avisos
- A edição no Pages CMS requer credenciais/autorização mantidas pelo adulto; a criança participa do cadastro acompanhada.
- Preços não foram inventados: o único produto cadastrado é um rascunho inativo.
- O clique no WhatsApp **não registra nem envia** o pedido automaticamente; o cliente precisa confirmar o envio da mensagem no aplicativo.
- O código não armazena pedidos nem nomes de clientes, e não gerencia estoque automaticamente.
- Hospedagem gratuita depende das condições e limites do GitHub Pages.
- O HTML aberto diretamente como arquivo não executa Liquid/Jekyll; teste após publicar no GitHub Pages ou com Jekyll local.
